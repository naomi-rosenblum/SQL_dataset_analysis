# Northwind Traders SQL Database Project

## Project Overview

This repository features a presentation that details a comprehensive SQL analysis project based on the well-known **Northwind sample database**. The goal was to address various business questions using SQL queries.

The project demonstrates skills in data analysis, SQL querying, data visualization, and presenting technical insights to non-technical stakeholders.

## Files in This Repository

*   `Northwind_SQL_Project.pdf`: The main presentation file, which includes an overview of business problems, the SQL queries used, resulting data tables and charts, and key takeaways for each question.
*   `README.md`: This file.

## Key Takeaways & Skills Demonstrated

*   **Customer Spending Analysis:** Calculated the average order value per customer and identified high-value clients using `AVG()`, `ROUND()`, `JOIN`, and `GROUP BY` functions.
*   **Product Popularity Analysis:** Determined total revenue per product to identify the most popular items for limited-edition runs.
*   **Hierarchical Data:** Created a SQL `VIEW` to outline top-selling products per year, demonstrating the ability to work with time-series data and aggregate sales.
*   **Data Filtering & Joins:** Used `WHERE` clauses and various `JOIN` types (e.g., `LEFT OUTER JOIN` on page 13) to filter specific customer orders and combine data from multiple tables.
*   **Data Presentation:** Translated complex SQL results into clear, understandable charts and summaries for business teams.

## Business Questions Explored (as seen in slides)

*   What is the average order value per customer?
*   How is revenue distributed across products to find the most popular item?
*   What were our top products each year?
*   What is the total revenue since the company's founding?
*   Can we get a list of all orders placed by Customer ID 10?
*   Can we get a list of all customers and all their order information?
*   What are the total sales per product category?
